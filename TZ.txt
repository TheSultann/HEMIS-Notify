Техническое Задание (Актуальная версия): Проект "HEMIS-Notify"

1. Название проекта
HEMIS-Notify

2. Цель проекта
Создать API-сервис (бэкенд), который подключается к информационной системе университета (HEMIS) для получения данных студента. На основе этого API реализован Telegram-бот, который автоматически отправляет пользователям их точное ежедневное расписание как в личные сообщения, так и в групповые чаты, ведет учет активности и предоставляет инструменты администрирования.

3. Технологический стек
Бэкенд: Node.js, Express.js
База данных: MongoDB (Mongoose)
Telegram Бот:
- node-telegram-bot-api для взаимодействия с Telegram API.
- node-cron для планирования ежедневных задач.
- axios для взаимодействия с собственным API-сервисом.

4. Архитектура проекта
Проект состоит из двух независимых, но взаимосвязанных модулей: Backend и TelegramBot.

Backend (API-сервис):
- server.js: Главный файл для запуска Express-сервера.
- models/User.js: Схема Mongoose для пользователя. Расширена полями для аналитики (lastActiveAt, createdAt, isBlocked).
- models/Group.js: Схема Mongoose для хранения связки академической группы и ID чата в Telegram.
- routes/schedule.js: Логика получения данных из HEMIS. Реализована защита от ошибок сервера HEMIS (эмуляция браузера, User-Agent) и валидация данных.
- routes/bot.js: Защищенные эндпоинты для Telegram-бота (регистрация, привязка/отвязка групп, статистика, рассылка, Logout).

TelegramBot (Сервис уведомлений):
- bot.js: Основной файл логики: обработка команд, динамическое меню (Admin/User/Group), трекер активности пользователей, планировщик рассылки.
- keyboards.js: Управление клавиатурами (обычное меню, админ-панель, инлайн-кнопки).
- .env: Хранение токенов, ключей шифрования и ADMIN_ID.

5. Ключевая логика работы

Логика API-сервиса (Бэкенд):
- Привязка аккаунта: Система ищет пользователя по telegramChatId. Реализован механизм Logout (полное удаление данных).
- Работа с группами: 
  - /bind-group: Привязка по названию (для админов).
  - /bind-by-user: Авто-привязка через профиль студента ("🔗 Привязать мою группу").
  - /unbind-group: Удаление привязки чата.
- Аутентификация в HEMIS: Автоматическое получение и обновление токена (refresh logic). Обработка ошибок 401 и 500.
- Аналитика: Сбор метрик DAU/WAU, подсчет уникальных групп и блокировок бота.

Логика Telegram-бота:
- Бесшовный онбординг: Выбор языка -> Вход -> Меню.
- Разделение прав (Scope): 
  - Личка: Полный функционал (/start, /me, /logout, расписание).
  - Группы (Участники): Только расписание.
  - Группы (Админы): Расписание + управление привязкой (/bind_me, /unbind_group).
- Админ-панель (по ID):
  - 📊 Расширенная статистика (Аудитория, Рост, Активность, Система).
  - 📢 Рассылка сообщений (Студентам / Группам) с предпросмотром.
- Трекер активности: Каждое действие пользователя обновляет lastActiveAt в базе для точной статистики.

Ежедневная автоматическая рассылка:
- 07:00: Расписание на сегодня.
- 19:00: Расписание на завтра.
- Проверка прогулов (каждые 30 мин): Уведомление при появлении нового "NB" в системе.

6. Статус проекта и решенные задачи
Проект полностью функционален и оптимизирован.
- Исправлена критическая ошибка 500 при авторизации (добавлены заголовки User-Agent).
- Реализована безопасная архитектура меню команд (Scope) для разных типов чатов.
- Внедрена система расширенной аналитики (DAU/WAU, Retention).
- Добавлен функционал массовой рассылки с подтверждением.
- Реализована удобная привязка бота в группах одной кнопкой.
